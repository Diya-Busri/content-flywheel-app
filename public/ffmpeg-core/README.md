# FFmpeg WebAssembly core (generated)

After `npm install`, `scripts/copy-ffmpeg-core.mjs` copies `@ffmpeg/core` from `node_modules` into this folder so the Video Timeline page can load the worker with same-origin URLs.

If this folder is empty locally, run:

```bash
npm install
```

Do not delete this `README.md`; other files here may be gitignored due to size.
